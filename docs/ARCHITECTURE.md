# GuardAI Architecture

## System Overview

Complete fullstack security application with Flutter frontend, Python backend, and Supabase database.

## Technology Stack

### Mobile (Flutter)
- Flutter 3.0+
- Provider / Riverpod (state management)
- Dio (HTTP client)
- Supabase SDK (backend & auth)

### Backend (Python)
- FastAPI
- Uvicorn
- Supabase SDK
- httpx

### Cloud & Services
- Supabase (PostgreSQL database & auth)
- Google Safe Browsing API
- OpenRouter / OpenAI / Anthropic (AI)

## Security Features

- Heuristic-based threat detection
- Real-time app scanning
- Web protection with phishing detection
- AI-powered security advisor
- Multi-device family protection
- Encrypted data in transit and at rest

## Deployment

### Mobile
- Google Play Store (Android)
- App Store (iOS)

### Backend
- Railway.app
- Heroku
- AWS Lambda
